# 墨汁英雄 · 射击 MOBA Demo

一款 **Splatoon × Deadlock** 风格的 **2D 俯视角英雄射击 MOBA** 单机 Demo。
- 墨水武器：射击在地面留下墨汁，可潜入己方墨汁加速与回墨，敌方墨汁减速。
- 英雄射击：3 名英雄（近战肉盾 / 刺客 / 远程射手），各自拥有不同的移动速度、转向速度、潜水速度、跳跃与武器，每名英雄 3 个小技能 + 1 个大招。
- 一条兵线：小兵波次推进、防御塔、基地核心，摧毁敌方基地获胜。
- 双伤害体系：子弹 / 魔法，配套抗性与穿透。
- 装备商店：防御 / 子弹攻击 / 魔法攻击 各 3 件，共 9 件，金币购买即生效。

## 运行

需要 Node.js ≥ 18 与 pnpm。

```bash
pnpm install
pnpm dev       # 开发调试，浏览器打开 http://localhost:5173
pnpm server    # 联机中继服务器（ws://localhost:8787）
pnpm build     # 产出静态站点到 dist/
pnpm preview   # 本地预览构建产物
```

## 联机（房间对战）

1. 先启动中继服务器：`pnpm server`。
2. 打开多个浏览器标签页访问游戏，主菜单点「联机房间」（或按 M）。
3. 一个标签页「创建房间」，拿到 6 位房间码；其他标签页「加入房间」输入房间码。
4. 大厅里点击空槽位加入（蓝方/红方各 3 位），点击自己的槽位切换英雄（重装/影/猎手）。
5. 房主点「开始游戏」，**空槽位自动由 AI 补位**。
6. 房主负责权威模拟，其余玩家通过中继收发操作与状态（移动/射击/潜水/技能/买装备均同步）。

> 需要服务端环境：本机使用 pnpm 11.7.0 / Node 24，依赖 `esbuild` 构建脚本已在 `pnpm-workspace.yaml` 中允许。

## 英雄与技能

- **重装**（近战肉盾）：墨汁散弹 + 墨刷。Q 硬化、E 冲撞、F 墨汁泼洒、R 地裂重击。
- **影**（刺客）：速射双刀。Q 瞬步、E 影刃（魔法 + 流血）、F 潜影、R 暗影突袭。
- **猎手**（远程射手）：墨汁步枪。Q 穿透弹、E 墨汁手雷（范围魔法）、F 疾射、R 全弹轨道炮。

## 装备（10 件）

- 防御：防弹背心(+子弹防) · 奥术护盾(+魔法防) · 均衡护甲(双抗) · 守护核心(绿色，受击超阈值生成临时护盾)
- 子弹攻击：速射枪管 · 重型弹头 · 穿甲弹头
- 魔法攻击：魔导之书 · 奥术核心 · 破法之刃

## 地图与伤害配色

- 单兵线 + **上下两条侧边道路**，可绕过防御塔绕后 / 偷袭 / 偷家。
- **伤害颜色区分**：子弹攻击 = 琥珀色，魔法攻击 = 紫色；投射物外圈用队伍色（蓝/红）标注阵营。
- **射程可视化**：防御塔攻击范围（虚线圆）、基地回血范围（绿圈）、自身武器射程（白圈）均清晰显示；受击有飘字伤害数字 + 白闪 + 红屏提示。
- 子弹有射程，英雄无法在防御塔射程外白嫖塔——想打塔必须进入塔的攻击范围。

## 补刀与金钱机制

- **补刀**：击杀小兵自动获得其赏金的**一半**，由击杀方所有存活队友**平分**。
- **掉落金钱**：死去的小兵原地掉落一枚「金币」，价值另一半赏金；用己方墨汁**涂到**它后，金币会被吸附到最近的队友身上并闪光收集，收集到的部分同样由队友平分（对方把墨汁涂上去可以干扰拾取）。
- 金币来源：补刀 + 掉落金钱 + 击杀英雄 + 推塔 + 随时间工资。

## 等级与成长

- 等级由**累计获得金钱**决定（每 600 金币升 1 级，上限 18 级），消费不降级。
- 升级获得基础属性增强，三种职业方向不同：
  - **重装（肉盾）**：+生命上限、+双抗、+生命回复。
  - **影（刺客）**：+移速、+转向速度、+子弹/魔法伤害。
  - **猎手（射手）**：+子弹伤害、+攻速、+生命上限。
- 回到己方基地附近会快速回血（基地回血光环）。

## 说明

- 单机：玩家（蓝方，可选英雄）+ 2 名队友 Bot 对抗 3 名敌方 Bot（红方）。
- 全部画面为程序化绘制，无外部美术资源。
- 所有数值集中在 `src/data/`、`src/heroes/`、`src/items/`，便于调参。
